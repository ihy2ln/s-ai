# S.Ai

A lightweight, workflow-first sampler and tracker for Android — M8's tracker
discipline, Serato Sample / FL Slicex-style chopping, and mobile-friendly
ergonomics, in one APK.

**Bring your own audio.** This project ships functionality, not sounds — no
bundled samples, loops, or presets.
