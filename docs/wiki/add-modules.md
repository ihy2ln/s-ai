# Add a module

**M → Add Module** opens the catalog (same idea as FL Mobile’s plugin list). Tiles, search, chips — not a file picker.

> S.Ai never asks you to browse to a `.vst3` on disk. See [Not a .vst3 host](not-a-vst-host.md).

## Find something

| Control | What it does |
| --- | --- |
| **Search** | Name, vendor, category, VST2/VST3 |
| **Instruments / Effects / Home** | Role tabs — see [Instruments vs Effects vs Home](instruments-effects-home.md) |
| **Built-in / VST2 / VST3** | Format chips (badges on tiles) |
| **Category** | Keys, Bass, Leads, Pads, Percussion, Dynamics, Space, Tone, Modulation, Utility |

Tap a tile. Next step depends on the role:

- **Home** — add the built-in module back to the workspace
- **Instrument** — [Add to Home or Channel Rack](rack-vs-mixer.md)
- **Effect** — [insert on a mixer strip](rack-vs-mixer.md) (some also add to Home)

## Enable / disable

**M → Plugins** turns catalog instruments and effects on or off. Built-in Home modules cannot be turned off.

If a tile looks dim: enable it in **M → Plugins**, then tap it again.
