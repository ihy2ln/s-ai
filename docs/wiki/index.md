# Start here

S.Ai is a landscape sampler and tracker. This guide is a **wiki**: short topics, tap a link.

**Sampler, Synth, Tracker, Channel Rack, and Pads stay.** The catalog adds VST2/VST3-*style* instruments and effects on top. It does **not** load desktop plugin files.
