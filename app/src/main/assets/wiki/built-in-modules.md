# Built-in modules stay

The catalog does **not** replace the modules you already use. They stay first-class on Home and in the **Home** tab of Add Module.

| Module | What it is |
| --- | --- |
| **Sampler** | Waveform, slices, record, To Rack |
| **Synth** | Filter, ADSR, live keys (your WAVs) |
| **Tracker** | 32-position song grid, 8 tracks |
| **Channel Rack** | Step rows, mute/solo/vol/pan, mixer route |
| **Pads** | 4×4 sample pad bank (add from the Home tab if it is off-screen) |

**M → Layout → Reset** restores Sampler, Synth, Tracker, and Channel Rack, default sizes, and box positions.

Adding a catalog instrument or effect never removes these. Removing a Home module with **−** keeps its data; add it back from **Home**.

## Same browser

**M → Add Module → Home** lists the built-ins next to VST2/VST3 tiles. Built-ins use the **IN** badge. They cannot be turned off in **M → Plugins**.
