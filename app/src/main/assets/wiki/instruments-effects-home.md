# Instruments vs Effects vs Home

The Add Module browser has three role tabs. Use the tab that matches what you want to *do*.

| Tab | For | Then |
| --- | --- | --- |
| **Home** | Sampler, Synth, Pads, Tracker, Channel Rack | Puts the module back on the workspace |
| **Instruments** | Playable catalog voices (Pulse Keys, Saw Lead, Sub Bass, …) | [Home or Channel Rack](rack-vs-mixer.md) |
| **Effects** | Filter, Comp, Reverb, EQ, Delay, Distort, … | [Mixer insert](rack-vs-mixer.md) (some also Home) |

**All** shows every role. Format chips (Built-in / VST2 / VST3) filter *inside* the tab.

## Quick picks

- Need the slicer again? **Home → Sampler**
- Need a lead? **Instruments → Leads** (or search `saw`)
- Need reverb on a vocal strip? **Effects → Space** (or search `reverb`)

Job recipes (vocals / guitar / drums / mix) are on [Vocals, guitar, drums, mix](jobs.md).
